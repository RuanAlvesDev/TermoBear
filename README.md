Nesse projeto nós procuramos fazer um sistema de verificação de temperatura do ambiente. Usando um arduino uno nos criamos a "Termobear" uma empresa fictícia com o propósito de ajudar pais e mães.

Nosso sistema de funcionamento é simples, um sistema arduino que fica denteo de um urso de pelúcia, aonde um sensor de temperatura faz a verificação para saber se está apropriada para uma criança. Se ele verifica que nao está na temperatura apropriada ele envia um sinal de luz via LED, contando tambem com uma vizualização em tempo real via LCD 16x2.

Nós acreditamos também que poderiamos usar um ESP32 para fazer o envio de um sinal Bluetooth, aonde ficaria um receptor no quarto dos pais, que enviaria um sinal sonoro de aviso quando a temperatura fosse baixa demais ou alta demais. Porém nao seguimos adiante com a ideia por se tratar de um trabalho escolar.
